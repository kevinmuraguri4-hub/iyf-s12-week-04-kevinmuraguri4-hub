## Project description
Beginner-friendly IYF Season 12 Week 4 practice covering variables, data types, functions, conditions, loops, arrays, objects, JSON, and array methods.

## Activities
1. **Tip calculator** — calculate a tip and final bill.
2. **Number guessing game** — guess a random number with hints.
3. **Student Grade Tracker** — add students and scores, calculate averages, filter, sort, and delete records.
4. **Lesson 7 and 8 exercises** — variables, data types, functions, control flow, arrays, objects, JSON, `map`, `filter`, `reduce`, and `find`.
5. **Daily challenges** — FizzBuzz, reverse a string, largest number, remove duplicates, and palindrome checker.

## Technologies
HTML5, CSS3, and vanilla JavaScript. No packages or installation required.

## How to run
1. Download this repository or clone it to your computer.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser (or use VS Code Live Server).
4. Select an activity from the home page.
5. For the exercise and challenge files, open the browser Developer Tools (F12) and select **Console** to see example outputs.

## What to practise
- Use `const` for values you do not reassign and `let` for values that change.
- Use strings, numbers, booleans, arrays, and objects appropriately.
- Write small reusable functions.
- Use `if/else` and loops to control program flow.
- Use array methods to transform, filter, combine, and search data.
- Convert JSON text to an object with `JSON.parse()` and objects to JSON text with `JSON.stringify()`.
